 CodeAlpha Internship – Data Analytics & Machine Learning Projects

This repository contains my projects completed during myCodeAlpha Internship, focusing on Data Analytics, Exploratory Data Analysis, Data Visualization, Natural Language Processing, and Machine Learning.

 📌 Projects Overview
Task 2 – Exploratory Data Analysis (EDA)

Performed Exploratory Data Analysis on the (Telco Customer Churn dataset) to understand customer behavior and identify patterns associated with churn.
Key Areas:

* Overall customer churn rate
* Customer demographics
* Contract types
* Internet service and additional services
* Customer tenure
* Monthly and total charges
* Multiple lines
* Payment methods
* Churn differences by gender and senior citizen status

Key Techniques:

* Data exploration
* Statistical analysis
* Data cleaning
* Group-by analysis
* Churn rate analysis
* Data visualization


Task 3 – Data Visualization

Developed visualizations using the Telco Customer Churn datasetto present customer churn patterns in a clear and meaningful way.

Visualizations Included:

* Customer churn distribution
* Churn by gender
* Churn by senior citizen status
* Churn by internet service
* Churn by contract type
* Churn by tenure
* Churn by monthly charges
* Churn by total charges
* Correlation heatmap

Tools Used:

* Python
* Pandas
* Matplotlib
* Seaborn

   Task 4 – Sentiment Analysis

Performed Sentiment Analysis on the Amazon Fine Food Reviews dataset using Natural Language Processing and Machine Learning techniques.

Reviews were classified into three sentiment categories:

* Positive
* Negative
* Neutral

Key Steps:

* Text preprocessing
* Lowercase conversion
* Punctuation removal
* Stop-word removal
* TF-IDF feature extraction
* Logistic Regression model training
* Model evaluation
* Emotion detection exploration
* * Python
* Pandas
* NLTK

* TF-IDF
* Logistic Regression
* Text2Emotion
